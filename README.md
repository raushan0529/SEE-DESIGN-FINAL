# Intelligent Industrial Worker Safety and Fatigue Monitoring System

Design Project-I, Alliance School of Advanced Computing, Alliance University.
Team: Vanlalliana Saiawi, Raushan Kumar, Aritra Sen, Mohammad Abdul Ahmed Shariff. Mentor: Dr. Shreenidhi H S.

- `index.html` is the whole website in one file (open it or deploy it as is).
