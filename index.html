All test windows

Learned fusion misses the fewest tired workers (1.3%), at the price of more false alarms. The wristband alone has the best overall accuracy.

Windows with the face hidden

With the face hidden the camera sees nothing (it misses every case). Fusion falls back to the wristband.

Architecture

1 · SensorsCamera (10 frames/s) and wristband (heart rate, SpO₂, motion at 50 Hz). Simulated here.
→
2 · Edge pipelineEye openness, eye-state CNN, motion spectrum, two XGBoost models, fusion.
→
3 · Backend APIChecks readings, raises and stores alerts, keeps an audit log.
→
4 · DashboardThis website: floor status, alert queue, worker detail.

In this page the edge pipeline and the backend both run inside your browser tab and talk through the same kind of requests a server would (see the console below). The Python version of the pipeline is the reference the parity check compares against. A decision is made every 5 seconds from the last 10 seconds of data.
